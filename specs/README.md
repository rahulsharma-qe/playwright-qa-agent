# Test plans

A test plan is a Markdown file that says, in plain English, what a user does on one part of the site and what they
should see. The test agents' planner writes plans here; a person can also write one by hand. A person reviews and
approves every plan in a pull request before any test is drafted from it.

Plans come from the normal Sprint 5 copy of Toolshop only. Never from the "with bugs" copy, and never from a list
of planted bugs. How to use the agents: [docs/ai-assisted-tests.md](../docs/ai-assisted-tests.md).
